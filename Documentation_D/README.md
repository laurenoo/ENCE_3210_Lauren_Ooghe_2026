# Weather Balloon Arduino Shield Redesign - PHASE 2
This is Phase 2 of the Weather Balloon Arduino Shield redesign. 
The goal was to redesign the system due to unavailable parts with a budget constraint of $147 and a weight constraint of 200g.
In this repository, all of the PCB design documents are listed. Phase 1 of this design can be found in the BalloonDesign/Phase1 folder inside of this repository. Below, you'll find the block diagram of the system with cost and weight estimates.
